# CreaBIM 1.1.1

CreaBIM now comes for **macOS**, and as **Linux packages**. The app itself is the same as 1.1.0.

## New downloads

- **macOS:** a universal `.dmg` for Apple Silicon and Intel Macs, macOS 11 or later. Drag CreaBIM to Applications and open it once. If macOS blocks it, go to *System Settings › Privacy & Security* and choose *Open Anyway*. The app isn't code-signed yet.
- **Ubuntu and Debian:** a `.deb` package: `sudo apt install ./CreaBIM-*-linux-x64.deb`. CreaBIM then appears in your applications menu.
- **Fedora and RHEL 10:** an `.rpm` package: `sudo dnf install ./CreaBIM-*-linux-x64.rpm`. It needs glibc 2.35 or later, so not RHEL 9.
- Windows and the Linux `.tar.gz` as before.

## Thanks

To the first outside contributors: the macOS, `.deb` and `.rpm` packaging came from a community pull request, and Mac users built and tested CreaBIM on their own machines on release day.
