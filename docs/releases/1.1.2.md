# CreaBIM 1.1.2

A patch for problems reported on GitHub after 1.1.1, and a friendlier question when you close with unsaved changes.

## New

- **Save the changes, redesigned.** Closing with unsaved changes now asks in a small card that says which file, how many changes and how long since it was last saved. Enter saves, Esc goes back. While it waits, the CreaBIM bird hovers over an open nest; when you save, the nest weaves shut, the dot turns green, the bird lands, and CreaBIM closes. A project that was never saved goes to Save as…; if a save fails (a read-only folder, a full disk), the card says why and CreaBIM stays open, so nothing is lost.

## Fixes

- **A crash when pointing at a door, window or piece of furniture in 3D** ([#22](https://github.com/chopinregis/CreaBIM/issues/22)). When CreaBIM looked for the face under the pointer (picking a workplane, drawing in 3D, the right-click menu), it could look in the wrong part of an element drawn in several parts, and stop with "range start index … out of range". It now uses the part that was hit.
- **Export names keep the dots in a project's name** ([discussion #17](https://github.com/chopinregis/CreaBIM/discussions/17)). `CreaBIM-1.1.1-test.creabim` now suggests `CreaBIM-1.1.1-test.ifc`, not `CreaBIM-1.ifc`. The same goes for every export, Save as, the notes and the project name on sheets.
- **The New project window fits a short screen** ([#24](https://github.com/chopinregis/CreaBIM/issues/24)). Its choices scroll between the title and the buttons, so Create and Cancel stay in reach, and it follows the window when the window gets smaller. The command palette keeps its search box and keys in view the same way.

Thanks to everyone who reported these.
