# Project information

*Manage › Project information* holds what the project is, where, and for whom. Every field is optional:

- **Project**: its name, the office's job number, the client, the status (*Planning application*, *Tender*…) and the issue date.
- **Site**: its name, the postal address, the latitude and longitude, the project's zero above sea level, and how far true north turns from the drawings' up.
- **Building**: its name and its use.

## Where it goes

- **Title blocks** read it: a title block's *job*, *project*, *client*, *address*, *status*, *issue_date*, *project_number*, *site* and *building* fields show these values on every sheet. A value set on one sheet still wins for that sheet.
- **IFC export** names the project, the site and the building from it.

Filling it in is one undo step, like any other edit.
