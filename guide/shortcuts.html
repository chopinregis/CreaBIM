Keyboard shortcuts

On this page
  • In the views
  • In Edit mode
  • Selecting
  • Move, rotate and scale
  • While drawing
  • Menus and the command palette

Every key CreaBIM knows. This page is made from the app's own menus and key list, so it always matches the version you are running.

Keys reach the views even after you click in a menu bar or the browser. Most keys act on the view under the pointer.

Tip: You don't need to learn these. Every command is also on a menu, a button or the right-click menu, and Ctrl+K finds any of them by name.

The keys below work in the views. Menu commands show their own shortcuts beside them in the app.

In the views

KeyWhat it does
HomeFrame everything in the 3D view
.Frame the selection in the 3D view
Ctrl+SpaceShow the area under the pointer alone, and back
Ctrl+Page UpThe previous workspace
Ctrl+Page DownThe next workspace
/Show the selection alone, and back
F3Snapping on or off
Alt (hold)Suspend snapping while you click
Shift+GShow or hide the guides in every view
Alt+ZX-ray: see through walls, slabs and roofs
Alt+F2Show or hide the trace reference under the view
Ctrl+PThe sheet in front as a PDF
DDimension (with nothing selected; with a selection, D shows or hides its live dimensions)
TTag
Ctrl+[Fold the project browser to a rail, or open it
Ctrl+]Fold Properties to its tabs, or open it
TabObject mode / Edit mode (with several things under the pointer: the next of them)
Shift+TTag all: every door, window, fixture and room not tagged yet
NNote (on a sheet: text on the paper)
Shift+AAdd: find any tool by typing (with nothing selected; with a selection, all of its type)
Page UpThe previous sheet, or view of the same kind
Page DownThe next sheet, or view of the same kind
Ctrl+Shift+PExport sheets: all, chosen or this one, as PDF
Shift+right-clickPut the pivot cursor here
F1Help about the tool in use (again to close)
SpaceFlip the selected wall, door, window or section, or the wall being drawn; with the Object tool, turn the next object a quarter
Shift+SpaceFlip the hand of the selected door
Ctrl+OOpen a project
Ctrl+SSave
Ctrl+Shift+TNext theme

In Edit mode

KeyWhat it does
Num1Pick points
Num2Pick edges
Num3Pick faces
clickOn a corner: pick it (Shift+click picks more)
dragOff the grips: pick the corners in a box; inside a hole: move it
DelRemove the picked corners or hole, never the element
BackspaceRemove the picked corners, as Delete
Double-clickOn a corner: remove it
right-clickOn a corner, an edge or a hole: add or remove corners, make an arc, remove the hole
TabWhile dragging a grip: type a length
EscCancel the drag; then drop the picks; then finish editing

Selecting

KeyWhat it does
Ctrl+ASelect everything
Alt+ASelect nothing
BThen drag in 3D: select with a box
Shift+clickAdd to the selection, or take away
TabPick the next of the elements under the pointer
Shift+TabPick the previous one
EnterOpen the selected element in Edit mode, or finish editing
Double-clickOn the selected element: open it in Edit mode
DelDelete what is selected
HHide the selection
Shift+HShow only the selection
Alt+HShow everything again

Move, rotate and scale

KeyWhat it does
MMove by a base point
GGrab: move with the pointer
RRotate
SScale
Shift+DDuplicate and move the copy
CtrlWhile moving: leave copies behind, or snap to steps
EnterFinish the move with the distance typed
BackspaceTake back the last digit typed
EscStep back, then cancel
EExtrude the selected face or sketch

While drawing

KeyWhat it does
Shift (hold)Keep lines square
EscDrop the clicks so far; again to go back to Select
EnterFinish an outline, a sketch or a detail component
1–4Slab, roof and shaft: Polygon, Rectangle, Fill room, From sketch
LDraw straight lines (slab outlines and sketches)
ADraw an arc (slab outlines and sketches)
CDraw a circle (sketches)
QRest on the point or edge under the pointer for its guide lines
KKeep the guide line under the pointer as a guide
